# Security

ArgonIQ is a development prototype, not a production service. Do not use it with
customer data, confidential manuals, production credentials, or safety-critical
instructions.

The code includes permission checks, tenant-scoped database access, row-level
security, and finite regression tests. These controls have not been independently
audited and should not be read as a certification or production-security claim.

If you find a vulnerability, email `facundocosimo@gmail.com` with the subject
“ArgonIQ security report.” Do not include credentials, personal data, or private
customer material in a public issue.
